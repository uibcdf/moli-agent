# Responsibilities and Boundaries

## Owns

- agent reasoning/orchestration logic;
- context-selection and reasoning policies;
- scientific delegation logic;
- interaction with humans and approval gates;
- agent-side planning state that is not authoritative project state.

## Does not own

- Sabueso SourceAssertions or resolved knowledge;
- Praxis Capabilities/Protocols;
- Nextia DiscoveryProjects, Evidence, or Decisions;
- MolSysSuite scientific APIs or modeling semantics;
- MolSys-AI software knowledge;
- authoritative scientific truth.

## Delegation

MOLI Agent may delegate MolSysSuite-specialist work to MolSys-AI Agent. Delegation does not transfer scientific ownership: Results return to the appropriate project/context owner.
