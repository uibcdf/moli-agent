# MOLI Agent Architecture

## Mission

Provide optional scientific reasoning and agency across the MOLI Platform without becoming the owner of scientific state or reproducible execution semantics.

## Context

MOLI Agent consumes structured Scientific Context assembled from:

- Sabueso — Knowledge;
- Praxis — Know-how;
- Nextia — Discovery context.

Context Assembly is richer than document retrieval and should preserve references to authoritative objects.

## Action levels

MOLI Agent may operate through:

`Discovery operation ↔ Capability ↔ Protocol ↔ specialist agent ↔ scientific API`

It may delegate MolSysSuite-specific operations to MolSys-AI Agent or access authorized APIs directly.

## Non-goals

MOLI Agent must not become:

- the persistence layer for Scientific Context;
- a replacement for DiscoveryEngine;
- a hidden owner of project state;
- a mandatory gateway to MolSysSuite;
- a validator that automatically promotes knowledge or methodology;
- a monolithic implementation of Sabueso, Praxis, Nextia, or MolSysSuite.

## Authority

Mutation and execution require explicit authority and approval policy. Human scientific judgment remains first-class.
